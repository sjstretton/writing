## Conventions in this section

- Each paper folder has `8.PreviousVersions`. Old versions carry a version number in the file name (`<Name>-v0.1.qmd`); the master carries its version in the YAML `version` field. Where no numbers existed, the older version is 0.1 and the current one 0.2.
- `3.RelatedPiecesAndLinks` holds related pieces of Stephen's that live with the paper. Pieces in other main folders are listed in `RelatedWork.md`, not copied.
