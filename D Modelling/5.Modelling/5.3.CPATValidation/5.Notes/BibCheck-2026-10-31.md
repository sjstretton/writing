# Reference check for 5.3, working paper v0.2 and brief v1.0 (31 Oct 2026)

Every source cited in either form was checked against the source itself: Crossref metadata (`api.crossref.org/works/<doi>`) for every DOI, the abstract for every article (Crossref, IDEAS, publisher or repository pages), and the passage for every specific number. The CPAT and CPAT-AI sources were read in the public repository (https://github.com/cpmodelai/cpat_ai, commit 108f976, 31 Oct 2026; raw files load without credentials, so the repository is public) and its website (https://cpmodelai.github.io/cpat_ai/). Each entry's `note` in `../CPATValidation.bib` records what was read. The brief's `.bib` is copied from the working paper's, only for the keys the brief cites.
