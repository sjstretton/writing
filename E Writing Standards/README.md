# E Writing Standards

The standards every paper, proposal and essay in this repo is written to. `NORMS.md` at the repo root is the short version; these files are the detail.

| File | Read it when |
|---|---|
| `writing-principles.md` | You are drafting or editing any prose. The core principles, drawn from Pinker, Strunk and White, McIntyre and McCloskey. |
| `writing-types.md` | You start a piece. It says which type the piece is, who reads it, how long it should be and what test it must pass. |
| `paper-standard.md` | You are writing or upgrading a working paper. The required structure and the pre-release checklist. |
| `ai-tells.md` | You finish a draft. The habits of AI-written prose to search for and remove. |
| `exemplars.md` | You want a model to imitate. Excellent policy, academic and popular writing, with what to learn from each. |
| `publishing-log.md` | You publish anything to Stephen's website. Log it here. |
| `templates/` | You start a new paper or concept note. |

## The order of work

1. Pick the type (`writing-types.md`).
2. State the question and the answer in two sentences.
3. Build the structure (`paper-standard.md` or the type's outline).
4. Draft with `writing-principles.md`.
5. Edit against `ai-tells.md`.
6. Run the skim test and the checklist.
